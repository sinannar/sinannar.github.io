## Agentic Engineering Day 2026

A hands-on workshop that takes agentic engineering from prompts to practice. Build SupportHub, a distributed customer-support application, while learning to guide coding agents through a repeatable **Research → Plan → Implement → Review** workflow.

## What you'll work on

- Develop features incrementally, from customers and tickets to attachments, activity tracking, SLA management, and dashboards.
- Use GitHub Copilot CLI, HVE Core, and agent skills to research the codebase, plan changes, implement features, and review the results.
- Work with .NET, ASP.NET Core, Blazor, and Aspire to build and observe a distributed application.
- Validate changes with builds, tests, and Aspire diagnostics, and organize work into stacked pull requests.

## Get started

Create your own repository from the starter template, then open it in GitHub Codespaces using at least four cores (eight preferred). Follow the workshop guide to verify your environment and run the application before starting the feature exercises.
